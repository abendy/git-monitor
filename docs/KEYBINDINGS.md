# Keybindings

## Navigation

| Key | Action |
|-----|--------|
| `j` / `↓` | Move down |
| `k` / `↑` | Move up |
| `g` | First item |
| `G` | Last item |
| `w` | Jump to working files |
| `h` | Jump to history (or toggle reflog/commits) |
| `b` | Jump to branches |

## Files (Staged/Working)

| Key | Action |
|-----|--------|
| `s` | Stage/unstage |
| `Space` | Open diff in pager |
| `d` / `Enter` | Show inline diff |
| `M` | Open in difftool |
| `P` | Push (when ahead) |
| `p` | Pull (when behind) |
| `f` | Fetch |

## History

| Key | Action |
|-----|--------|
| `h` | Toggle commit log/reflog |
| `Space` | Expand/collapse commit |
| `[` / `]` | Previous/next page |
| `y` | Copy short SHA |
| `c` | Copy full SHA |
| `R` | Interactive rebase onto commit |

## Commit Files (when expanded)

| Key | Action |
|-----|--------|
| `Space` | Open in pager |
| `d` | Inline diff popup |
| `M` | Open in difftool |

## Branches

| Key | Action |
|-----|--------|
| `Space` | Expand/collapse branch |
| `Enter` | Checkout branch |
| `c` | Copy commit SHA |

## Command Mode

| Key | Action |
|-----|--------|
| `:` | Enter command mode |
| `a` | Browse aliases |
| `o` | Expand output popup |
| `Enter` | Execute |
| `Esc` | Cancel |
| `↑` / `↓` | History navigation |

## Popup/Overlay

| Key | Action |
|-----|--------|
| `j` / `k` | Scroll |
| `g` / `G` | Top/bottom |
| `Ctrl+d` / `Ctrl+u` | Page down/up |
| `q` / `Esc` | Close |

## General

| Key | Action |
|-----|--------|
| `m` | Context action menu |
| `r` | Refresh |
| `?` | Help |
| `q` / `Esc` | Quit |
